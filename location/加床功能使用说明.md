# 医院床位管理系统 - 加床功能使用说明

## 新增功能概述

系统已成功为**所有房间（601、602、603、605、606、607室）**添加**动态加床功能**，支持在床位不足时通过用户操作增加床位，并提供灵活的床位布局调整能力。

## 已支持加床功能的房间

✅ **601室** - 支持加床、拖拽调整  
✅ **602室** - 支持加床、拖拽调整  
✅ **603室** - 支持加床、拖拽调整（已迁移现有"加床"床位）  
✅ **605室** - 支持加床、拖拽调整（包含隔离病房管理）  
✅ **606室** - 支持加床、拖拽调整（已迁移现有"加床"床位）  
✅ **607室** - 支持加床、拖拽调整（包含感染病区管理）

## 主要新增功能

### 1. 动态加床功能
- **功能描述**: 当现有床位不足时，用户可以点击"+ 加床"按钮添加新的床位
- **操作方式**: 点击加床按钮后，系统进入加床模式，用户可在房间内点击选择加床位置
- **智能冲突检测**: 系统会自动检测并阻止在现有设施或床位上放置加床

### 2. 拖拽式床位调整
- **功能描述**: 用户可以通过拖拽方式调整加床的位置
- **操作方式**: 直接拖拽加床到新的位置，系统会实时验证位置合法性
- **视觉反馈**: 拖拽过程中提供视觉反馈，冲突位置会有提示

### 3. 床位管理增强
- **床位识别**: 加床会显示为虚线边框，并标注"(加床)"字样
- **删除功能**: 加床可以通过床位编辑界面删除（原有床位不可删除）
- **数据持久化**: 加床信息自动保存到本地存储

### 4. 实时统计显示
- **床位统计**: 实时显示总床位数、原有床位数、加床数量
- **使用情况**: 显示使用中床位数和空床数
- **主页更新**: 主页会自动更新显示各房间的床位信息

## 使用指南

### 添加加床的步骤

1. **进入房间页面**
   - 点击主页上的房间卡片进入具体房间（如601、602、603、605、606、607室）

2. **启动加床模式**
   - 点击右上角的绿色"+ 加床"按钮
   - 按钮变红色"取消加床"，页面提示"点击选择加床位置"

3. **选择床位位置**
   - 在房间布局图中点击想要放置加床的位置
   - 系统会检测位置冲突，如有冲突会提示重新选择

4. **完成加床**
   - 选择合适位置后，系统自动创建加床
   - 加床以虚线边框或特殊标识显示

### 管理加床

1. **编辑加床信息**
   - 点击加床打开编辑界面
   - 可以输入患者信息、设置床位状态、添加备注

2. **移动加床位置**
   - 直接拖拽加床到新位置
   - 系统会验证新位置是否合法

3. **删除加床**
   - 点击加床进入编辑界面
   - 点击红色"删除床位"按钮即可删除

### 数据管理

1. **数据保存**
   - 所有床位数据（包括加床）自动保存到浏览器本地存储
   - 数据包括患者信息、床位状态、备注等

2. **数据同步**
   - 床位统计信息实时更新
   - 主页床位数量信息自动同步

## 常见问题解答

### Q: 加床数据会丢失吗？
A: 不会。加床数据保存在浏览器本地存储中，除非手动清除浏览器数据，否则数据会一直保留。

### Q: 可以添加多少个加床？
A: 理论上没有限制，但受房间空间约束。系统会自动检测空间冲突。

### Q: 加床可以拖拽到任意位置吗？
A: 不可以。系统会检测冲突，只能拖拽到不与现有设施或床位冲突的位置。

### Q: 原有床位可以删除吗？
A: 不可以。只有加床可以删除，原有床位是系统固定配置。

### Q: 加床信息会在PDF导出中显示吗？
A: 是的，加床会在PDF导出中正常显示，包括床位布局和患者信息。

## 开发者说明

### 扩展其他房间

要为其他房间添加加床功能，需要：

1. **创建房间管理器类**：
```javascript
class Room601Manager extends BedManager {
    constructor() {
        super('room601', room601Config);
    }
    
    render() {
        // 实现具体的渲染逻辑
    }
}
```

2. **更新HTML文件**：
```html
<script src="bed-manager.js"></script>
<script src="room601-enhanced.js"></script>
```

3. **配置房间布局**：
```javascript
const room601Config = {
    canvasSize: { width: 500, height: 400 },
    beds: [...],
    facilities: [...]
};
```

### 自定义样式

可以通过修改CSS来自定义加床的外观：

```css
.bed.additional {
    border: 2px dashed #your-color !important;
    background-color: #your-bg-color;
}
```

### 事件监听

系统提供了多个事件钩子：

```javascript
// 床位添加完成
room602Manager.on('bedAdded', function(bedId) {
    console.log('新增床位:', bedId);
});

// 床位删除完成
room602Manager.on('bedDeleted', function(bedId) {
    console.log('删除床位:', bedId);
});
```
