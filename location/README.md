# 601室床位分布图系统

## 项目概述
这是一个用于管理601室床位分布的在线系统，支持床位信息录入、状态管理和可视化显示。

## 最新修改 (2025年)

### 精准布局还原 (基于图片)
- **布局尺寸**: 调整为1200x600像素，更符合实际比例
- **床位位置**: 根据图片精准定位所有20张床位
- **氧源标识**: 位于床位之间，提供清晰的视觉分隔
- **机械吊塔**: 每个床位左侧都有，采用专业设计
- **洗手池**: 位于机械吊塔下方，符合实际布局
- **设施布局**: 库房、电脑、储物柜、门等设施精确定位
- **蓝色分隔线**: 添加垂直分隔线，划分不同区域

### 布局特点
- **上排床位**: 9个水平床位（601-15到601-05）
- **左侧床位**: 2个横向床位（601-16, 601-17），与中间区域Y轴对齐
- **中间区域**: 4个横向床位（601-19到601-22）位于库房区域
- **右下角**: 2个横向床位（601-01, 601-02）
- **独立床位**: 601-18和601-03
- **设施**: 库房、电脑、储物柜、多个门
- **氧源标识**: 16个氧源接口，位于床位之间
- **机械吊塔**: 20个机械吊塔，每个床位一个
- **洗手池**: 15个洗手池，位于机械吊塔下方

## 功能特性

### 床位管理
- 床位信息录入（病人姓名、状态、备注）
- 床位状态管理（空床、在院、预出院）
- 实时统计（病人总数、预出院人数）

### 可视化元素
- **床位**: 白色矩形，显示床号和病人信息
  - 上排和下排床位：竖向长方形（40x80像素）
  - 左侧和右侧床位：横向长方形（旋转90度）
- **氧源接口**: 蓝色◉符号，位于床位之间
- **机械吊塔**: 灰色"塔"标识，位于床位左侧
- **洗手池**: ⊙符号标识
- **门**: 白色方框样式，40x60像素，显示"门"字

### 交互功能
- 点击床位打开编辑弹窗
- 支持批量操作
- 数据自动保存和统计

## 使用方法

1. 打开 `index.html` 或 `test.html`
2. 点击任意床位进行信息录入
3. 选择床位状态（空床/在院/预出院）
4. 填写病人姓名和备注信息
5. 系统自动统计病人总数和预出院人数

## 技术实现

### 核心配置
- 床位布局配置在 `app.js` 中的 `bedLayoutConfig`
- 氧源标识位置在 `oxygenSources` 数组中定义
- 机械吊塔通过 `hasTower` 属性控制显示

### 样式设计
- 响应式布局
- 现代化UI设计
- 清晰的视觉层次
