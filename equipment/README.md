# 设备信息收集服务器

本项目基于 Python Flask 框架，实现手机端通过浏览器填写表单，数据通过 WiFi 传输到电脑并自动保存。

## 使用方法

1. 安装依赖

在 PowerShell 终端运行：

```
pip install flask
```

2. 启动服务器

```
python server.py
```

3. 手机和电脑连接同一 WiFi，手机浏览器访问：

```
http://电脑IP:5000
```

填写表单后，数据会自动保存到 `data.csv` 文件。

## 文件说明
- server.py：主服务器代码，处理表单和数据保存。
- data.csv：收集到的设备信息数据（首次提交后自动生成）。
- README.md：项目说明文档。

## 数据整理

所有提交的数据会保存在 `data.csv`，可用 Excel 或其他工具进行整理分析。

## 注意事项
- 请确保电脑和手机在同一局域网。
- 如需自定义表单字段或页面样式，可修改 `server.py` 中的 HTML 部分。
