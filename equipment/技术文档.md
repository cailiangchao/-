# 设备管理系统高级查询功能实现文档

## 项目概述

本项目为新生儿科设备管理系统添加了现代化的数据查询功能，使用户能够根据多种条件灵活查询设备使用记录，并支持数据导出功能。

## 功能特点

1. **多条件查询**：支持按设备名称、编号、运行状态、使用人、床号、患儿信息等多个字段进行筛选
2. **日期范围查询**：支持使用日期和消毒日期的范围筛选
3. **数据排序**：支持按任意列进行升序/降序排序
4. **分页显示**：结果分页展示，可调整每页显示数量
5. **数据导出**：支持将查询结果导出为CSV文件
6. **响应式设计**：适配不同屏幕尺寸的设备
7. **直观的筛选标签**：已应用的筛选条件以标签形式显示，方便用户了解和移除

## 技术实现

### 架构设计

采用Flask蓝图（Blueprint）模式组织代码，将查询功能模块化，便于维护和扩展：

- `server.py`：主应用程序，处理设备信息录入和基本查看
- `search.py`：查询模块，包含高级查询页面和API

### 前端实现

前端使用现代Web技术栈：

- **Bootstrap 5**：提供响应式布局和基础UI组件
- **Flatpickr**：日期选择器，支持日期范围选择
- **Bootstrap Icons**：提供丰富的图标支持
- **原生JavaScript**：实现动态数据加载、排序、分页等功能

### 后端实现

后端基于Flask框架，主要功能包括：

1. **数据查询API**：`/api/search` 端点接收查询参数并返回过滤后的数据
2. **数据导出API**：`/api/export` 端点生成CSV文件供下载
3. **页面渲染**：`/search` 端点提供查询界面

### 数据流程

1. 用户在查询界面设置筛选条件并提交
2. 前端JavaScript收集表单数据，发送AJAX请求到后端API
3. 后端处理请求，从CSV文件读取数据并应用筛选条件
4. 后端返回JSON格式的结果数据
5. 前端接收数据，应用排序和分页逻辑，渲染到表格中

## 代码集成

在主应用程序中集成查询模块：

```python
# 在server.py中导入和注册蓝图
from search import search_bp
app.register_blueprint(search_bp)
```

在原有界面中添加链接到查询页面：

```html
<div class="actions">
    <a href="/" class="btn">返回表单</a>
    <a href="/search" class="btn">高级查询</a>
</div>
```

## 遇到的问题与解决方案

### 1. 文件修改权限问题

**问题**：尝试直接修改server.py文件时遇到权限错误：
```
Error writing file: {"errno":-4048,"code":"EPERM","syscall":"mkdir","path":"e:\\","name":"Error","message":"EPERM: operation not permitted, mkdir 'e:\\'"}
```

**解决方案**：采用模块化设计，创建单独的search.py文件实现查询功能，然后在server.py中导入该模块。

### 2. 服务器启动问题

**问题**：修改后的服务器可能未能正常启动，没有看到预期的输出信息。

**解决方案**：
- 使用不同端口尝试启动服务器
- 检查网络连接状态
- 尝试导入模块验证代码语法正确性

### 3. 数据文件路径问题

**问题**：在不同电脑上运行时，数据文件路径可能不一致，导致找不到数据文件。

**解决方案**：
- 在server.py中添加`ensure_data_file()`函数调用，确保数据文件存在
- 使用相对路径引用数据文件，提高代码可移植性

## 使用说明

1. 启动服务器：
   ```
   python server.py
   ```

2. 访问查询页面：
   ```
   http://localhost:5000/search
   ```

3. 设置查询条件并点击"查询"按钮

4. 查看结果，可以：
   - 点击列标题排序
   - 调整每页显示数量
   - 使用分页导航
   - 点击"导出结果"下载CSV文件
