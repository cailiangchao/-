# 床位显示与数据录入系统技术文档

## 1. 核心功能更新

### 1.1 床位状态系统
```javascript
// 床位状态定义
const bedStatus = {
  empty: '空床',          // 无患者
  occupied: '占用',       // 有患者
  discharge_planned: '拟出院' // 计划出院
};

// 状态自动判断逻辑
function getBedStatus(bedId) {
  const bedInfo = room601BedData[bedId];
  if (!bedInfo || !bedInfo.patientName || bedInfo.patientName.trim() === '') {
    return 'empty'; // 无患者自动设为空床
  }
  return bedInfo.status || 'occupied'; // 默认占用状态
}
```

## 3. 系统架构

### 3.1 数据流
```
[床位点击] → [打开编辑模态框] → [用户输入] → [自动状态判断] → 
[数据保存] → [本地存储] → [界面重新渲染]
```

### 3.2 核心数据结构
```javascript

  "bed-id": {

```

## 4. 使用说明

### 4.1 基本操作流程
1. 点击床位打开编辑对话框
2. 输入患者信息
3. 选择床位状态（或自动判断）
4. 点击确认保存
5. 系统自动更新显示

### 4.2 状态显示规则
- 空床：浅蓝色背景，蓝色边框
- 占用：浅橙色背景，橙色边框  
- 拟出院：浅绿色背景，绿色边框
- 状态图标显示在床位右上角
